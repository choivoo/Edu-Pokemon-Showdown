# 포켓몬 퀘스트 팬 에디션 (Pokémon Quest: Fan Edition)

원작 *포켓몬 퀘스트*의 진행 방식을 **도트풍 2D 웹게임**으로 옮긴 비공식 팬게임입니다. (3D 큐브 대신 도트 스프라이트, 스토리는 새로 썼습니다.)
**가로 전용 단일 화면** 게임이라 캠프·섬 지도·전투·팀 편성이 모두 한 화면 안에서 창을 열고 닫는 식으로 이어집니다.

> **고지:** 이 프로젝트는 비공식·비상업 팬게임이며, 포켓몬(Pokémon)은 Nintendo / Game Freak / The Pokémon Company의 상표입니다.
> 포켓몬 이미지는 레포에 저장하지 않고 [PokeAPI/sprites](https://github.com/PokeAPI/sprites) 에서 런타임에 불러옵니다.
> URL 은 `src/data/sprites.ts` 한 곳에서만 관리하므로 나중에 오리지널 몬스터로 쉽게 바꿀 수 있습니다.

## 줄거리

하늘에서 별이 떨어진 날 그 조각이 모여 만들어졌다는 **별모래섬**. 섬 한가운데 별빛 제단의 **오로라 프리즘**이 폭풍에 여섯 조각으로 깨지자
포켓몬들이 난폭해졌습니다. 미라 박사와 함께 각 지역 우두머리가 품은 조각을 되찾으세요. 모두 모으면 **끝없는 별길**이 열립니다.

## 게임 방법

- **베이스캠프:** 요리 냄비, 도감, 상점, 팀 편성이 있는 거점. 동료들이 돌아다닙니다.
- **요리:** 냄비에 재료 5개를 넣습니다. 재료는 원작처럼 **색(빨강·파랑·노랑·회색) / 식감(부드러움·딱딱함) / 종류(버섯·달콤함·식물·광물·신비로움)** 성질을 갖고,
  어떤 성질이 얼마나 들어갔는지(조금·많이·듬뿍)로 **18가지 레시피** 중 하나가 정해져 그 타입의 포켓몬이 찾아와요. 레시피 목록은 냄비 창의 **레시피** 버튼에서 볼 수 있어요.
  재료의 희귀도 합이 클수록 요리 등급(기본·좋음·매우 좋음·스페셜)이 올라가 희귀한 친구가 올 확률이 높아집니다. 신비로운 재료(무지개머티리얼·신비의 조개껍질)를 듬뿍 넣으면 전설의 수프예요.
- **섬 탐험:** 섬 지도에서 지역과 스테이지를 고릅니다. 지도에 **추천 전투력**이 표시되고, 내 파티 전투력과 비교해 보세요.
- **전투(탑다운 자동 전투):** 파티 3마리(빨강·초록·파랑)가 필드를 돌아다니며 싸웁니다. 근접형은 달려가 때리고 원거리형은 멀리서 쏩니다.
  하단의 별 버튼으로 포켓몬별 **필살기**(쿨다운)를 쓰고, 자동 필살기·배속(×1~3)·일시정지·포기를 지원합니다. 타입 상성, 급소, 범위기, 웨이브 사이 소량 회복, 보스 웨이브가 있습니다.
- **파워스톤:** 포켓몬마다 **4×3 격자**가 있고, 레벨이 오르면 칸이 열립니다. 모양이 다른 스톤(1칸·2칸·3칸·ㄱ자)을 회전해서 배치하세요. 칸이 클수록, 별이 많을수록 효과가 커져요. 같은 스톤 2개는 상점에서 합성합니다.
- **성장:** 클리어 보상은 코인·경험치(파티 전원)·재료·파워스톤. 보스는 첫 클리어 시 동료로 합류합니다. 코인으로 즉시 레벨업도 가능해요.

## 그래픽과 음악 (전부 코드로 만들었어요)

- **도트 아트:** 맵(타일·나무·바위·절벽·웅덩이·용암·수정), 캠프의 냄비와 모닥불, 섬 지도, 항해하는 배, 타이틀 로고, 모든 아이콘(재료·스톤·버튼 등)을
  이미지 파일이나 이모지 없이 **코드로 한 점씩 찍어서** 그립니다. (`src/art/`) 포켓몬 스프라이트만 PokeAPI에서 불러옵니다.
  개발 중에는 주소 뒤에 `#art` 를 붙이면 도트 그림을 한눈에 볼 수 있어요.
- **배경음악:** 마림바·신스 플럭·서브 베이스·펄스 리드·플루트·패드·브라스·벨 같은 악기와 킥·스네어·클랩·하이햇·탐 같은 드럼을 오실레이터와 노이즈로 만들고,
  경쾌한 전자음 팝 느낌의 곡(타이틀·캠프·섬 지도·전투·보스전·이야기)과 짧은 효과 음악(승리·패배·레벨업·요리)을 **직접 작곡**했습니다. (`src/lib/songs.ts`, 원작 곡을 베끼지 않은 오리지널)
  `#music` 주소로 열면 곡을 렌더링해 파형 통계와 스펙트로그램을 확인할 수 있어요.

## 저장 키 (다른 기기에서 이어하기)

진행 상황은 브라우저(`localStorage`)에 자동 저장되지만, **저장 키 + 암호 키** 한 쌍을 만들어 두면 다른 기기나 데이터를 지운 뒤에도 이어서 할 수 있습니다.

1. 캠프 우상단 **🔑 저장 키** (또는 타이틀의 **데이터 이전**) → **저장 키 만들기**
2. 화면에 **저장 키**(긴 문자열)와 **암호 키**(`XXXX-XXXX-XXXX-XXXX`, 매번 랜덤 생성)가 나옵니다. **둘 다 스크린샷이나 메모, .txt 파일로 보관**하세요.
3. 다른 기기에서 **데이터 이전 → 저장 키로 불러오기**에 두 가지를 붙여 넣으면 그 시점의 모험이 복원됩니다.

- 저장 데이터는 압축 후 암호 키로 **AES-GCM(PBKDF2)** 암호화되어 서버 없이 동작합니다. 암호 키 없이는 저장 키를 열 수 없습니다.
- **암호 키를 잃어버리면 복구할 수 없습니다.** 서버에 계정이 없기 때문에 이미 잃어버린 키를 다시 만들어 낼 방법도 없어요. 진행이 쌓이면 새 키를 다시 만들어 주세요(캠프에서 알려 줍니다).
- 옛날 키로 불러오면 그 시점의 데이터로 돌아갑니다.

## 실행 방법

```bash
npm install
npm run dev        # 개발 서버
npm test           # Vitest (전투 엔진, 파워스톤 격자, 요리 레시피, 저장 키 암호화, 악보 검증 등)
npm run build      # 프로덕션 빌드 (dist/)
```

모든 화면은 960×540 가상 해상도로 그려지고 창 크기에 맞춰 통째로 확대/축소됩니다. 세로로 들면 "가로 화면으로 돌려 주세요" 안내가 나오고, 타이틀의 **전체화면** 버튼으로 전체화면(+가로 고정)을 켤 수 있어요.

## 배포 (GitHub Pages)

`main` 브랜치에 push 하면 `.github/workflows/deploy.yml` 이 테스트 → 빌드 → 배포를 수행합니다.
레포 **Settings → Pages → Source** 를 **GitHub Actions** 로 설정하세요. (`vite.config.ts` 의 `base: './'` 로 하위 경로에서도 동작)

## 새 포켓몬/스토리 추가

- 포켓몬: `src/data/pokemon.json` 에 `{ id(도감 번호), name, types, stats, rarity(1~4), basic, special }` 추가. (기술 id 는 `moves.json`)
- 지역·스토리 대사: `src/lib/stages.ts` 의 `AREAS` / `PROLOGUE`.
- 재료와 끌어들이는 타입: `src/lib/cooking.ts` 의 `INGREDIENTS`.
