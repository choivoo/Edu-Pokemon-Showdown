# Pokémon Quest Fan Edition v2.3.0 — 2D Pixel Quest Reimagined

Entirely redesigned 2D title/boot experience, 12 freshly composed original Web Audio BGM pieces plus 4 new jingles. Default Pokémon artwork remains PokéAPI Generation V 2D dots with the original fallback.

**Gameplay:** Full 1,359 Bingo candidate descriptions (9 × 151 first-generation species), the 3 independently selected Bingo effects for each Pokémon and correct evolved-species candidate lookup. Typed attack/status passives; beam, melee, dash, cone, burst and multi-hit move geometries; improved enemy target heuristics; verified stage 1-1~1-4 and 2-1~2-2 segment encounter ratios including rare boss spawns; individual recipe odds calculator and top-four estimate display; independent primary/secondary move stone bonuses and move training. Legacy encrypted game saves and existing 93-stage campaign stay compatible.

**Accuracy caveats:** Original exact encounter charts have been verified for **6** of 63 original stages (others use existing approximated procedural encounters). Recipe-specific Pokémon probabilities are mathematically normalized **estimates**, not independently validated official odds. Multi-hit timing, collision physics and enemy navigation are new 2D representations rather than original frame-by-frame reconstructions. See `PARITY_AUDIT_2_3.md` for sources/limitations.

No original copyrighted music, dialogues, game extracted graphic resources or 3D. This remains an unofficial, noncommercial fan adaptation, not affiliated with Pokémon rights holders. The provided asset is a built **web ZIP**, not an Android APK or offline desktop app.
